# 周易音乐播放器

基于 Qt 6 + QML 的本地音乐播放器，采用网易云音乐风格暗色主题，支持播放列表管理、LRC 歌词显示、红心收藏等功能。

## 功能
**本地音乐播放** — 支持 MP3 / WAV / OGG / FLAC / M4A 等常见音频格式
**播放列表管理** — 批量导入音频文件，自动读取元数据（标题、艺术家、专辑、时长），支持删除歌曲
**三种播放模式** — 顺序播放、随机播放、单曲循环
**LRC 歌词显示** — 自动匹配同目录下 `.lrc` 歌词文件，当前行红色高亮居中滚动
**红心收藏** — 点击红心收藏歌曲，"我喜欢"列表独立查看，关闭程序后收藏数据持久化
**网易云风格暗色主题** — 五层背景递进、品牌红强调色、圆角控件、悬停反馈
**启动画面** — 程序启动时显示品牌 Logo 和标题,2 秒后淡出
**侧边栏导航** — 推荐（发现音乐/本地音乐）和我的音乐（播放列表/歌词/我喜欢）分组
**持久化存储** — 播放列表和收藏数据自动保存，下次启动自动恢复

## 技术
Qt6.11跨平台:C++框架
QML/Qt Quick:声明式UI
QMediaPlayer:音频播放引擎
QAbstractListModel:播放列表数据模型
QSettings:播放列表与收藏持久化存储
CMake 4.1:构建系统

## 使用说明
1. **导入音乐** — 菜单栏「文件 → 打开音乐文件」或快捷键 `Ctrl+O`，选择音频文件导入
2. **播放控制** — 底部控制栏提供播放/暂停、上一首/下一首、播放模式切换、音量调节
3. **切换视图** — 左侧侧边栏切换播放列表、歌词、"我喜欢"三个视图
4. **收藏歌曲** — 底部歌曲信息区右侧红心按钮，点击收藏/取消收藏
5. **删除歌曲** — 播放列表中每行右侧 × 按钮可删除歌曲
6. **主题切换** — 菜单栏「视图 → 切换浅色/深色主题」
